# Accepted milestones and remaining scope

This is the shared acceptance index for the integration guides. **Accepted** means the named milestone passed separate exact-source, resulting-master and actual copied-handoff gates. It does not mean whole-project completion, a change to the user's active installation, independent approval, live-service parity or a public binary release. Later commits and working changes need their own qualification; equal source trees do not make source-bearing archives interchangeable.

## Accepted behavior versus open work

| Area | Accepted bounded subset | Still open / not established |
| --- | --- | --- |
| Coordinator / Unified | Default `tools`, raw `nativeTools`, identical `projectedTools` alias; saved return-wait ceiling and positive numeric shell lookup IDs. | Full tool-specific API/error/truncation equivalence, larger concurrency/lifetimes and PTY/ConPTY. Numeric lookups are not native authority. |
| Web | `verified-v1`; nine-family `experimental`; public-URL open/find/screenshot; protected text projection. | Owned opaque reference issuance/lifetime, click/continuation, native citation-widget parity and Web media downloads. Public URLs are not service-reference authority. |
| Images | Bounded inline PNG/JPEG/GIF/WebP and owned-reference forwarding; `generatedImage()` publication; imagegen normal-result projection with raw/warning fallback. | Audio, legacy detail hints, broader remote media and upstream data-URL parity. Forwarding is not generation, fetching or saving. |
| Context / notifications | Reload-required `experimental-context`; final-hook, serialized-request-confirmed current native text; primitive `await notify(value)` output tied to the original exec across waits. | Automatic idle model turns, arbitrary history reconstruction, reload/crash restoration of authority and full upstream lifecycle equivalence. |
| Native lifecycle | Original ownership, publication ordering and bounded collection; normal cohorts finish with zero active/draining scopes. | Cancellation is not confirmed closure. The acknowledgement-fault cohort deliberately retains four quarantined scopes; it is not cleanup or crash/fsync recovery. |
| Distribution | Separately accepted source/master/copied bundles and scoped notices. | Complete redistribution qualification and authorized public upload/download. Software licensing does not establish hosted-service entitlement. |
