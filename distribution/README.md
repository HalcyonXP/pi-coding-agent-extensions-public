# Windows bundle tooling — 0.3.0-private.1

Builds a deterministic, source-specific Windows x64 bundle with the compatible patched Pi 0.85.1 packages, locked production dependencies, one cohesive extension, verified prebuilt helper, provenance/notices and isolated installer/launcher. The version and stable “private” names identify a non-upstream pre-release variant, not a claim about source visibility or published asset availability.

**No installation-ready release is implied by source publication.** A [verified local preview handoff](../docs/openai-integration/LOCAL-PREVIEW.md) and a public binary release are separate outcomes; public redistribution clearance is not a prerequisite for calling an actually accepted local handoff ready for the maintainer's next installation action. Read the [release contract and pre-execution verification](../docs/openai-integration/RELEASE-CONTRACT.md), [build/install/update/rollback guide](../docs/openai-integration/PRIVATE-RELEASE.md) and [acceptance boundaries](../docs/openai-integration/FINAL-ACCEPTANCE.md).

Original first-party tooling, tests, documentation and root package/lock metadata in this directory are licensed under [Apache-2.0](LICENSE); see [NOTICE](NOTICE). This is not a blanket license for bundled dependencies, upstream code or unrelated repository components.

The builder requires a clean committed source and new output paths, including the sibling `<output>.build-inputs` retention directory. It checks canonical Git blobs, exact native source/patch equality and immutable consumer-lock integrity; no lock regeneration, stock-host fallback, global SDK replacement or runtime compilation/download. Compiler/reference packages are explicit pinned build inputs, never runtime payload. Deterministic file-only tar/gzip uses bounded manifest/path/reparse checks.

Two separate output builds must match, followed by real tar extraction (including spaced paths), distribution/accept.mjs and distribution/accept-profile.mjs. CI uses Node 24; compare its exact-source manifest/archive digest with local supported-Node reproduction. Source tests alone are not installed-artifact acceptance. CI uploads only manifests/checksums, no executables or deployment assets.

The archive includes canonical docs/openai-integration/*.md with the installation/release guides and supported-surface map, plus the distribution/documentation LICENSE and NOTICE files; installed acceptance checks their presence. The canonical `distribution/payload-policy.json` pins the exact six original host tarballs and ten-file DOOM example. After the unchanged locked npm installation, source-only curation moves those originals byte-identically into `<output>.build-inputs`, outside the runtime tree/archive. All other installed files and notices must remain byte-identical. Changed/missing/extra exclusion inputs, other archive candidates, links or existing retention paths fail closed before moving inputs; no repacking, deletion or automatic policy regeneration. The manifest records the policy digest and retained-file inventory, and both installed commands verify that the excluded demo and archives are absent. This curation is not clearance for unrelated embedded works.

The delivered package/lock JSON files retain build provenance; the immutable runtime payload is **not an npm installation workspace**. Its original `file:artifacts` inputs deliberately remain outside it. Do not run npm install/update/ci in an accepted bundle or copy the retained inputs back into it. Reproduction starts from matching trusted source using the documented builder, not by mutating the runtime archive. It excludes profiles, credentials, sessions, user images, development dependencies and private local receipts. Development validation tools and root PUBLICATION.md remain in the matching trusted source.

`distribution/verify-download.mjs` is a source-only offline checker, intentionally not included in the bundle. Run it from independently trusted source with six explicit argument pairs: `--archive`, `--manifest`, `--source`, `--release`, `--archive-sha256`, `--manifest-sha256`. Input file paths must be absolute. It streams a regular archive up to 768 MiB and reads a regular detached manifest up to 8 MiB, rejects changed hashes/incompatible source-version-platform-Node identity, and reports no input paths. It does not download, extract, inspect tar contents, execute bundle code, install, authenticate, sign or upload. Its result only matches already trusted pins; it neither establishes that trust nor protects files changed afterward. See the release contract for obtaining pins and the complete sequence.

`distribution/audit-bundle.mjs` is a separate source-only, read-only inventory of an already verified bundle. It retains nested package/version identities, notice candidates, native payloads and archives without importing package code. Candidate notices are not scope/redistribution clearance; see the current [blocked redistribution review](../docs/openai-integration/REDISTRIBUTION.md). The selected unsigned technical preview is not ready for binary publication.

Profiles are always new and separate from immutable bundles. Launch holds an exclusive lifetime lock. Rollback uses native capability-name exclusions while preserving Fast/footer, native models, preferences/auth/history/originals; no unsafe retired loader is restored. Never recycle unconfirmed locks by PID lookup, overwrite a live profile, rebind an old receipt or import active credentials automatically.
