## Native ownership and shared vocabulary

- Preserve native model/provider/auth/cache/transport ownership, ordinary tools, auto-compaction, Fast/footer/settings, hooks/events/accounting, generated originals and third-party notices. Do not replace providers or use stock-host, unrestricted/portable, invocation-time compilation or download fallbacks.
- Production Code requires Windows x64, Node 24/25, .NET Framework 4.8, matched patched Pi 0.85.1 and the verified prebuilt helper. Prefer maintained Node 24 LTS. Curated bundles are not npm workspaces.
- **Native scope/invocation** means host-owned authority. Shell IDs, provider `call_id`, native ToolCall IDs, evidence IDs and presentation metadata are distinct; lookup values do not confer authority. ID-contract changes must update native quiet-poll/grouping classification and matched artifacts together. Do not admit historical IDs to live tools.
- **Finalization, publication and RPC admission** are separate boundaries. `tools` projects recognized normal results only after the required native/evidence/RPC checks; `nativeTools` preserves raw `{result,isError}`, and `projectedTools === tools`. Hook changes, errors, loss, unknown or oversized results keep wrappers/evidence. Do not rewrite historical scripts or artifacts silently.
- **Return wait** is not process lifetime; cancellation is not confirmed closure. `wait` collects Code cells; `write_stdin` addresses numeric shell lookup IDs. Quiet polling must not hide meaningful output/errors or imply token savings. Restricted coordinator JavaScript does not sandbox deliberately delegated shell commands.
- **Notification** means primitive `await notify(value)` additional native output for the original exec across adopted waits—not a toast, completion, usage event or permission to manufacture an idle turn. Journal/queue acceptance is not consumption. Historical orphan notices remain labelled history, not invented calls.
- Code collector return is not whole native prompt finalization. Normal successful-work cohorts require zero final active/draining scopes. The separate acknowledgement-fault cohort genuinely publishes once before delaying acknowledgement and deliberately retains exactly four quarantined scopes; never describe those as cleaned up. No crash/fsync-recovery or physical-process-state claim follows.

## Context, Web and media boundaries

- `/openai-tools` is the capability entry point; `/fast` and `/openai-jobs` are not aliases. Persist preferences, not jobs/cells/credentials/references/authority. Saved and effective settings differ where reload is required; preserve malformed files for repair.
- `verified-v1` and `experimental` are context-free. `experimental-context` is an explicit reload-required conversation-disclosure opt-in, not secret scrubbing. Context requires final native hooks, actual serialized Responses bytes, successful completion and current invocation. No ancestry reconstruction, replay or context-free downgrade.
- Context bounds remain 512 messages/128 blocks/64KiB text/2MiB serialized request. Web input retains the last two native users and intervening assistant text, with 4,000 shared assistant-prefix UTF-8 bytes and an 8,192-byte serialized DTO. These are Pi restrictions, not upstream token/middle-truncation parity.
- Web admits one to four bounded operations under native/provider leases; verified-v1 stays narrow and experimental supports nine source-derived families. Current open/find/screenshot use public URLs, not opaque continuation. `results` remains opaque source evidence. Do not invent authoritative DTO fields or mint ownership from citation-looking text, copied metadata, hashes or matching strings. Native `ev_...` references are not service `ref_id` values.
- Inline PNG/JPEG/GIF/WebP inputs use own data descriptors, a 32KiB decoded cap, one declared frame, 4,096-pixel edge and 4,194,304-pixel canvas bounds. Proxy traps remain watchdog-bound; container/JPEG framing checks are not pixel decoding or a codec sandbox.
- `generatedImage()` forwards protected image content and an optional unverified output hint; it does not generate, fetch or save. Projected imagegen `image_url` is an owned Pi reference, not upstream data-URL parity. Preserve originals and warnings; never replay generation merely to recover a copy or metadata.
